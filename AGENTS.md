# AGENTS.md

VisionForAll is an open-source Edge AI accessibility assistant designed to help visually impaired users understand their surroundings using computer vision and voice interaction.

## Project Goals
- Provide scene descriptions from camera input
- Enable text reading using OCR
- Support voice interaction (STT + TTS)
- Work in offline or low-connectivity environments

## Agent Tasks
Agents working on this repository should focus on:

1. Improving vision pipelines for scene understanding
2. Optimizing performance for edge devices
3. Enhancing accessibility and usability
4. Improving local knowledge retrieval
5. Expanding plugin architecture

## Design Principles
- Privacy first
- Offline-first architecture
- Modular plugins
- Accessibility focused

Agents should avoid introducing mandatory cloud dependencies unless optional.
