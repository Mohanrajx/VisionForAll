# Security Policy

## Reporting a Vulnerability
Please do **not** open public issues for security vulnerabilities.

Send a private report with reproduction details to: `security@visionforall.local` (placeholder for maintainers).
Include affected versions, impact assessment, and proof-of-concept if possible.

## Supported Versions
As an early project, only the latest `main` branch is actively supported.

## Security Principles
- Offline-first by default (no telemetry, no cloud APIs).
- Least data retention (audio is not stored unless users explicitly implement it).
- Prefer local processing and explicit opt-in for networked features.
